## About this Repository

This is the source repository for [khemrajpradhan.com.np](https://khemrajpradhan.com.np), a single-page personal website built with vanilla HTML, CSS, and JavaScript. No build step, no framework, no dependencies.

## Technical Stack

- **Code:** Vanilla HTML5 + CSS3 + JavaScript (no frameworks, no build step)
- **Hosting:** GitHub Pages
- **DNS & CDN:** Cloudflare
- **SSL:** Cloudflare (automatic)
- **Email:** Zoho Mail (`email@khemrajpradhan.com.np`)
- **Forms:** Google Forms (booking inquiries)
